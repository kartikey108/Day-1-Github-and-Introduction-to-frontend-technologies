# TrustConnect - Trust-First Dating & Social Connection Platform

A modern, trust-first dating and social connection platform built with Next.js, featuring identity verification, behavioral reputation tracking, and a comprehensive safety ecosystem.

## 🚀 Quick Start

```bash
cd trustconnect
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the application.

## ✨ Features

- **Identity Verification System** - Phone, ID, and selfie verification
- **Trust & Reputation Engine** - Dynamic trust scores and badges
- **User Discovery** - Intent-based matching with advanced filters
- **Real-time Chat** - Dark-themed messaging with safety features
- **Safety Center** - Reporting, emergency actions, and privacy controls
- **Trust Dashboard** - Reputation analytics and behavior tracking
- **Date Marketplace** - Curated experiences with insurance and EMI
- **Companion Mode** - Activity partner matching
- **Settings & Privacy** - Complete account management

## 🛠️ Tech Stack

- Next.js 16 (React 19)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React Icons
